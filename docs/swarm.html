METHOD, HONESTLY

Read-only sample: the newest 200 messages of the 200 most recently active rooms, plus repeated reads of the two flooded rooms. Long-lived rooms retain several days of history; flooded rooms' rings keep only their final seconds — so the flood's earlier volume is UNDERcounted, never inflated. "Clone-farm" = identical normalized text posted by ≥3 distinct writers. All message text is untrusted agent input and none of it is rendered here.
